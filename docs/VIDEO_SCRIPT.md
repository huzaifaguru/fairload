# Demo video

## Option 1: use the finished silent video

`docs/media/fairload_demo.webm` runs about 2 minutes with on-screen captions, so no one needs a microphone. Upload it to YouTube as Public or Unlisted and paste the link into Devpost.

## Option 2: a teammate adds a voice

Open the file in a video editor and read this over it, or record the screen while using the live app. Times match the silent video.

| Time | On screen | Say |
|---|---|---|
| 0:00 | Title card | This is FairLoad, from team 404 Error Found. It helps a food bank plan where limited food goes each week. Delaware is our public test case. The results are simulated, and the Food Bank of Delaware is not a partner. |
| 0:06 | Map | This is real public data: 31 Delaware ZIP codes, from mobile pantry records and Census poverty counts. |
| 0:12 | Map | Each dot is a ZIP. Color shows the share of need met, and size shows people in poverty. |
| 0:17 | Result cards | A linear program plans eight weeks of shipments. It runs in the browser with no server. |
| 0:22 | Truck breakdown on | Now a truck breaks down at Milford. I switch that on, and the plan re-solves. |
| 0:30 | Result cards | Need met falls. These cards compare FairLoad with a simple rule under the same limits. |
| 0:36 | Switching map view | We can compare plans on the map. This is the capped poverty-share rule, and this is FairLoad. |
| 0:43 | Fairness slider | This slider sets the share of need every ZIP should reach. The chart shows the trade-off at each target. |
| 0:51 | Pin and price | Managers know things a model does not. Here one forces a shipment. |
| 0:59 | Cost panel | FairLoad shows what that costs and which ZIPs give up the most. The person decides. |
| 1:06 | Bottlenecks | It also shows what limits the plan, and what another truck or site would be worth. |
| 1:13 | Test results | We tested it on 30 simulated 12-week runs per scenario, none used to set the model. |
| 1:19 | Chart | FairLoad met 2.3 to 3.7 points more need than the strongest rule we tested, in all six scenarios. |
| 1:25 | What we found | We report the limits too. There is little gain when trucks are plentiful, and waste did not consistently fall. |
| 1:32 | Sensitivity table | Every assumption can be changed, and we show how the result moves. |
| 1:37 | Data tab | Real data and assumptions are kept separate, and another food bank can upload its own file. |
| 1:43 | Closing card | The next step is checking this against real fleet, fixed pantry and need data. Thank you. |

The actual video is about 2:01 long, so check these times while recording and adjust your pace if needed. Keep the words "simulated" and "not a partner" whichever way you record it.
